## 📖 About The Challenge

The **50 Days 50 Projects (Python)** challenge is a daily coding journey demonstrating the versatility and power of Python. It progresses from fundamental scripting and algorithmic logic to complex desktop GUIs, browser automation bots, REST API integrations, machine learning classifiers, and full arcade games.

Whether you're a beginner looking for hands-on project ideas or an intermediate developer seeking modular code snippets, this repository offers practical implementations across multiple domains.

## ⚡ Getting Started

### 1. Prerequisites

Ensure you have **Python 3.8 or higher** installed on your system:
```bash
python --version
```

### 2. Clone the Repository

```bash
git clone https://github.com/anujtiwari1427/50-DAYS-50-PROJECTS-PYTHON.git
cd 50-DAYS-50-PROJECTS-PYTHON
```

### 3. Create a Virtual Environment

It is recommended to use a virtual environment to manage dependencies:

* **Windows:**
  ```powershell
  python -m venv venv
  .\venv\Scripts\activate
  ```

* **Linux / macOS:**
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```

### 4. Install Dependencies

Install all necessary packages via the included `requirements.txt`:
```bash
pip install -r requirements.txt
```

## 🚀 Running Any Project

Each project is self-contained within its respective day folder. To run a project:

### 🎮 CLI / Standard Scripts (e.g. Day 01 - Password Generator)
```bash
python "DAY 1/project_day01.PY"
```

### 🖥️ GUI / Desktop Apps (e.g. Day 24 - Calculator)
```bash
python "DAY24/CALC.py"
```

### 🕹️ Pygame / Arcade Games (e.g. Day 50 - Pygame Tic-Tac-Toe)
```bash
cd DAY50
python tic_tac_toe_GUI.py
```

### 🌐 Web Interfaces (e.g. Day 42 - Currency Dashboard)
Simply open the HTML file in any modern web browser:
```bash
# On Windows
start DAY42/currency_converter_ui.html

# On macOS
open DAY42/currency_converter_ui.html

# On Linux
xdg-open DAY42/currency_converter_ui.html
```

> **Note for Selenium Bots (Days 43, 47, 49):**
> Ensure Google Chrome and the matching `chromedriver` or `webdriver-manager` are configured on your system.
